# G's Avengers — Clipboard

Clipboard history and an emoji picker, built into [G's Avengers](../../README.md) as a helper app.

- **fn V** opens the history at the text cursor; pick an item to paste it where you were typing.
- **fn E** opens the emoji panel.
- Text, links, images and files; smart cleanup; history stays on your Mac.

Built by the root `build.sh` (`swift build -c release --package-path Modules/GsClipboard`). Inside G's Avengers it never checks for updates on its own; it is updated with the main app.
