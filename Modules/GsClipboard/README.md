# G's Avengers — Clipboard

Clipboard history and an emoji picker, built into [G's Avengers](../../README.md). The code lives in `Sources/Vorssaint/Clipboard` and runs inside the one G's Avengers process; this folder keeps its pictures and docs.

- **fn V** opens the history at the text cursor; pick an item to paste it where you were typing.
- **fn E** opens the emoji panel.
- Text, links, images and files; smart cleanup; history stays on your Mac.
